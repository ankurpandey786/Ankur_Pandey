# Ankur Pandey — Personal Portfolio

A static, frontend-only personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or use any simple static server:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Included

- Premium dark developer UI
- Smooth scrolling
- Scroll progress indicator
- Reveal-on-scroll animations
- Interactive ServiceNow project cards with modal case studies
- Responsive mobile layout
- Professional profile image
- Downloadable resume PDF
- No database, backend, microservices or MID Server required
